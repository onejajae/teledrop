# ADR 0006 — 게스트 업로드 티켓을 제거한다

- 상태: 채택
- 날짜: 2026-09-21

## 결정

제품 범위를 소유자 한 명의 파일 업로드와 공유로 좁힌다. 게스트 업로드 티켓의 발급·관리·업로드 화면, 만료·재시도·소진 정책과 저장 모델을 제거한다.

인증 경로는 다음 둘이다.

| 경로 | 권한 |
|---|---|
| 소유자 세션 | 웹 UI의 업로드·조회·수정·삭제·공개 |
| API 키 | 비공개 업로드와 소유자 접근 링크 반환 |

모든 업로드의 비공개 기본값, 별도 공개 단계, 드롭 비밀번호, `Teledrop.Core`와 `Teledrop`의 의존 경계는 유지한다.

## 결과

- `/tickets` 관리 화면과 `/u/{path}` 게스트 업로드 경로를 제거한다.
- 티켓 엔티티·서비스·DI 등록·테스트와 드롭의 티켓 참조를 제거한다.
- 기존 DB 전환은 제공하지 않는다. 티켓 추가 마이그레이션을 제거하고 모델 스냅샷을 드롭만 있는 초기 스키마에 맞춘다. 기존 DB나 파일을 자동으로 초기화하지 않는다.
- ADR 0001·0004는 폐기하며, ADR 0003의 인증 경로 수를 둘로 변경한다. 이전 ADR과 구현 완료 기록은 이력으로 남긴다.
