# Python을 버리고 C#과 Razor Pages로 간다

서버 렌더링으로 UI를 어차피 다시 쓰고 백엔드에서 살아남는 코드도 절반 정도라, 이전 비용이 아니라 장기 적합성으로 언어를 고른다. .NET은 파일 서버의 핵심인 Range 응답(`PhysicalFile`)과 쿠키 인증, EF Core 마이그레이션을 기본으로 갖추고 Razor 템플릿 오류를 빌드에서 잡으며, 개발자가 업무에서 C#을 쓴다.

## 버린 안

- **Python + Jinja2** — 템플릿 오류가 런타임 500이라 잘 쓰지 않는 화면에서 늦게 드러난다
- **Blazor** — 파일 업로드가 SignalR 회로를 거치고, JS와 회로 없이는 화면이 움직이지 않아 HTML 폼에서 멀어진다. 화면이 폼과 목록뿐이라 컴포넌트 상태 모델이 값을 하지 않는다
