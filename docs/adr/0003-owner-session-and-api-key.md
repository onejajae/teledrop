# 웹은 소유자 세션으로, API는 업로드 하나를 API 키로 연다

웹 UI는 ASP.NET Core의 암호화 쿠키 세션으로 인증하고 서버에는 세션 상태를 두지 않는다. API는 iOS 단축어가 쓰는 `POST /api/upload` 하나뿐이며 환경변수의 API 키 하나로 연다. API 업로드는 항상 private이라 돌려주는 Share Link는 소유자만 열 수 있고, 조회·수정·삭제·공개는 웹에서 한다.

## 버린 안

- **JWT 세션**(main) — 만료가 토큰에 들어 있어 클라이언트가 재발급과 만료 감지를 떠안는다
- **세션 테이블** — 폐기는 비밀번호를 바꿔 모든 기기의 세션을 끊는 것으로 충분하다
- **API 키 테이블과 발급·폐기 UI** — 사용자가 한 명이라 기기별 폐기가 필요 없다
- **API의 `public=true`** — 공개는 되돌릴 수 없으므로 공유 시트 한 번으로 일어나게 하지 않는다
- **조회·수정·삭제 API** — 단축어가 부르지 않는 엔드포인트를 열어두지 않는다
