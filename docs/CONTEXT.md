# teledrop

자체 호스팅 서버에서 돌리는 개인 파일 공유 도구. 원래 구상은 **instant cloud** — 지금 당장 파일을 올려두고 바깥에서 꺼내 쓴다. 서버 주인 한 명이 쓰며, 시한부 티켓으로 남에게서 파일을 받는다.

설계와 범위는 [DESIGN.md](DESIGN.md), 결정 배경은 [adr/](adr/).

## Language

**Drop**:
공유의 단위. 파일 하나와 그 메타데이터(제목, 설명, 공개 여부, 비밀번호)를 묶은 것. 컬렉션이 아니며 언제나 파일 하나에 대응한다.
_Avoid_: Content, Item, File, 게시물

**Slug**:
드롭을 가리키는 URL 식별자. 자동 생성(형용사 + 명사)하거나 소유자가 직접 정한다. 비밀이 아니다.
_Avoid_: key, id, 주소

**Share Link**:
드롭에 접근하는 URL. slug를 포함한다.
_Avoid_: 공개 링크, 다운로드 링크

**Drop Password**:
개별 드롭에 거는 비밀번호. 소유자의 로그인 비밀번호와 무관하며 재사용하지 않는다.
_Avoid_: password 단독 사용

**Publish**:
private 드롭을 public으로 바꾸는 행위. 업로드와 분리된 별도의 단계이며, 드롭 상세 화면에서 파일을 보면서 한다. 되돌려도 공개 기간에 이미 받아간 것은 회수되지 않으므로 실질적으로 되돌릴 수 없다.
_Avoid_: 공유하기, 공개 설정

**Owner**:
서버의 주인이자 유일한 사용자. 계정 개념이 없으므로 "사용자"라는 말은 이 한 명만 가리킨다.
_Avoid_: user, admin, account, 관리자

**Guest**:
업로드 티켓을 받아 파일을 보내는 사람. 계정이 없고, 올린 뒤 아무것도 조회할 수 없다.
_Avoid_: 방문자, 익명 사용자

## 업로드 티켓

**Upload Ticket**:
게스트가 파일 하나를 올릴 수 있게 하는 시한부 크리덴셜. 티켓 경로와 티켓 코드 두 조각으로 이루어지며 둘 다 맞아야 한다.
_Avoid_: 업로드 코드, 승인 코드, 초대 코드 — "코드"는 아래 티켓 코드만 가리킨다

**Ticket Path**:
티켓의 URL 조각. 업로드 페이지의 위치를 가리킬 뿐 비밀이 아니다.
_Avoid_: 임시 링크, 티켓 slug

**Ticket Code**:
티켓의 비밀 조각. 업로드 페이지의 폼에 입력하며, 티켓의 방어를 전담한다.
_Avoid_: 비밀번호, PIN

**Consumed**:
티켓이 업로드 성공으로 소진된 상태. 만료(expired)와 구분한다 — 만료는 시간이 지나서 죽은 것이고, 소진은 제 역할을 다해서 죽은 것이다.
_Avoid_: used, 사용됨

## 크리덴셜

**API Key**:
소유자의 iOS 단축어가 쓰는 장기 크리덴셜. 환경변수로 하나만 두며, 업로드와 공유 링크 반환만 할 수 있다.
_Avoid_: 토큰, 액세스 키

**Session**:
소유자가 웹 UI에 로그인한 상태. 클라이언트 코드는 세션의 수명 관리에 관여하지 않는다.
_Avoid_: 토큰, JWT — JWT를 세션으로 쓰지 않는다. 인증 맥락에서 "티켓"이라고도 부르지 않는다(ASP.NET의 AuthenticationTicket과 무관하게, 이 프로젝트에서 티켓은 Upload Ticket뿐이다)
