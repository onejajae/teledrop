# AGENTS.md

## 1. Project Purpose
- teledrop is a private file-sharing platform for self-hosted servers.
- The goal is secure, direct access to personal files without relying on third-party cloud accounts in potentially unsafe environments.
- The product is delivered through a REST API and an authenticated web UI for upload, sharing, and file access management.

## 2. Tech Stack
- Backend: `FastAPI`
- Web UI: SSR with `Jinja2` + `htmx`
- Component styling: `daisyUI` + `Tailwind CSS`

## 3. Run (uv)
- Use `uv` as the default runtime workflow.

## 4. Test (pytest)
- Use `pytest` for tests.

## 5. Commit Style
- Use Conventional Commits for all commit messages.
